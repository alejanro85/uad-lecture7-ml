# Веб-формы для наглядной иллюстрации данных и моделей

Модель в блокноте понятна аналитику. Руководителю, заказчику или комиссии нужна **форма**: ввёл параметры объекта (скважина, замес, станок, студент) → увидел вероятность события, решение при выбранном пороге и цену ошибки.
В этой папке собраны готовые формы для всех кейсов лекции и инструкции, как сделать такую же форму для своего датасета ЛР2.

## Готовые формы

| Форма | Где открыть | Что нужно | Срок жизни ссылки |
|---|---|---|---|
| Статическая страница (HTML + JS) | [GitHub Pages](https://alejanro85.github.io/uad-lecture7-ml/) · исходник [`docs/index.html`](../docs/index.html) | только браузер | постоянно |
| Блокнот с формами Colab, ipywidgets и Gradio | [06_web_forms_gradio в Colab](https://colab.research.google.com/github/alejanro85/uad-lecture7-ml/blob/main/notebooks/06_web_forms_gradio.ipynb) | аккаунт Google | Gradio-ссылка — пока работает ячейка (не дольше недели) |
| Приложение Streamlit | [`streamlit_app/app.py`](streamlit_app/app.py) | Python локально или Streamlit Community Cloud | постоянно, пока приложение развёрнуто |

Все три используют один файл описания кейсов [`streamlit_app/cases.py`](streamlit_app/cases.py) и тот же конвейер, что блокноты 00–05:
масштабирование → one-hot → логистическая регрессия, разбиение 75/25, `random_state=42`. Поэтому числа совпадают со слайдами: например, для students при пороге 0,5 модель находит 22 из 29 «не сдаст», а при пороге 0,3 по вероятности «не сдаст» (это то же, что 0,7 по вероятности «сдаст») — 25 из 29 при 9 ложных тревогах.

### Что показывает каждая форма

| Кейс | Что двигать на лекции | Управленческий вывод |
|---|---|---|
| Студенты (эталон) | порог и цену пропуска | кого пригласить на консультацию; почему порог 0,5 — не закон |
| Энергетика: устойчивость сети | время реакции τ и эластичность g | какие участники сети «раскачивают» режим |
| Строительство: бетон ≥ 30 МПа | воду, цемент и возраст | В/Ц — главный рычаг; строгий порог защищает от приёмки слабого бетона |
| Производство: AI4I 2020 | крутящий момент и износ инструмента | редкий отказ: accuracy 0,97 при полноте 0,14 — нужна другая метрика и порог |
| Нефтегаз: факел (синтетика) | крен, ветер, дни с осмотра | шлюз TO BE из ЛР1 «нужен ли внеплановый осмотр» работает на данных |

| Уровень | Средство | Когда выбирать | Трудоёмкость |

| 6 | **Статическая страница на GitHub Pages** | постоянная ссылка без сервера; модель — формула в браузере | 1–2 часа (с помощью LLM быстрее) |
| — | **Yandex DataLens, Looker Studio, Datawrapper** | дашборды разведки (тренды, структура, KPI) без кода; ML-форму не строят | низкая |

Перед показом проверьте, открывается ли выбранный сервис из сети вуза: доступность зарубежных облачных платформ (Hugging Face, Streamlit Cloud, Google) может отличаться. GitHub Pages и локальный запуск Streamlit — самые надёжные варианты.

## Как развернуть

**Статическая страница (GitHub Pages).** Модели уже выгружены в [`docs/models.json`](../docs/models.json).
Если изменили `cases.py`, пересоберите: `python webapps/export_static.py`, затем закоммитьте `docs/`.
Публикация: Settings → Pages → Branch `main`, папка `/docs`. Документация: [GitHub Pages](https://docs.github.com/pages).

**Streamlit локально.**

```bash
cd webapps/streamlit_app
pip install -r requirements.txt
streamlit run app.py
```

**Streamlit Community Cloud.** [share.streamlit.io](https://share.streamlit.io) → New app → репозиторий `alejanro85/uad-lecture7-ml`, ветка `main`, файл `webapps/streamlit_app/app.py`. Инструкция: [документация Streamlit](https://docs.streamlit.io/deploy/streamlit-community-cloud).

**Gradio.** Откройте блокнот 06 в Colab → «Среда выполнения → Выполнить все» → ссылка `*.gradio.live` появится под последней ячейкой. Публичные ссылки Gradio действуют не дольше недели, для постоянной ссылки используйте Hugging Face Spaces ([руководство Gradio](https://www.gradio.app/guides/sharing-your-app)).

## Как сделать форму для своего датасета ЛР2

1. **Быстро:** в Streamlit-приложении выберите «Загрузить свой CSV», укажите целевую переменную и событие. Заранее удалите идентификаторы и признаки-«подсказки ответа».
2. **Свой код:** скопируйте ячейку Gradio из блокнота 06 и подставьте свои признаки и модель.
3. **С помощью LLM:** используйте шаблоны из [`PROMPTS.md`](PROMPTS.md).

## Чек-лист качества веб-формы

- Вероятность в форме совпадает с `model.predict_proba` в блокноте на 2–3 тестовых строках (на статической странице это проверяется автоматически при загрузке, см. консоль браузера).
- В форме нет признаков-утечек (тип отказа TWF…RNF в AI4I, `stab` в энергетике, итоговый балл в students).
- Диапазоны ползунков взяты из данных (1–99 перцентиль), а не придуманы; указаны единицы измерения.
- Показаны порог и цена ошибок: что значит ложная тревога и что значит пропуск в терминах процесса.
- Указаны источник данных и ссылка на блокнот с полным анализом.
- Синтетические данные подписаны как синтетические.
